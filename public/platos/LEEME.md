# Fotos de los platos

Pon aquí las fotos (Unsplash o Pexels, licencia libre) con el id del plato como nombre,
por ejemplo `clasica-27.jpg`. Formatos: jpg, png, webp o avif. Proporción recomendada 4:3,
mínimo 1200 px de ancho.

`npm run dev` y `npm run build` regeneran `lib/data/photo-manifest.json` automáticamente.
Si un plato no tiene foto, la interfaz muestra un degradado con su inicial.
